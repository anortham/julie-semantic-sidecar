# v0.1.0 stable candidate proof — 2026-07-29

## Verdict

The local `v0.1.0` stable candidate is ready for the hosted publication
pipeline. The exact Apple arm64 archive is reproducible across independent
absolute build roots and passes package validation, CPU and Metal conformance,
backend selection, fallback, concurrency, and throughput checks on physical

uploaded, or released. Windows and Linux were manually tested at RC5, but the

## Reproducibility

Two clean release builds used different absolute `CARGO_TARGET_DIR` roots:

- `build-6/target`
- `build-7/target`

The archives and package manifests matched byte-for-byte. Both archives had
SHA-256
`f23045d25e88a9e6e068c7a1b2a78e2ea0e86f3db5c15e81f99997fe142b1ed9`.
The packaged binary contained no absolute workspace or evidence-root strings.

The initial proof exposed three sources of build-root leakage: Rust paths,
native C/C++ paths, and the raw path-remap arguments embedded in the runtime
build identity. Packaging now remaps Rust and native compiler paths while the
runtime identity excludes only source-path remap arguments. Other Rust
code-generation flags remain identity-bound. A focused red-green regression
test and an independent review cover the identity behavior.
