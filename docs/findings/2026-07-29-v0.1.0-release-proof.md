## Verdict

`v0.1.0` was published from commit
`02bea1ae261a9c9bcb491caac36e033c318a8a92` as a stable, non-draft,
non-prerelease GitHub release with four portable archives and four matching

## Release gates

- Push CI run: `30499321347`
- Approval-gated artifact run: `30499681823`
- Both runs completed successfully at the exact release commit.
- The Windows Server 2022 broker lifecycle job passed all 10 tests.
- Linux and Windows conformance jobs passed.
- Dependency audit, formatting, Clippy, Rust tests, Python tests, and all four
  artifact-validation lanes passed.

The first Windows lifecycle run exposed three invalid platform assumptions in
the tests and a production cancellation retry loop. The release was held while
the ACL and connection-close assertions were corrected and Win32
`ERROR_OPERATION_ABORTED` was preserved so Rust `write_all` cannot retry a
cancelled pipe write forever.
