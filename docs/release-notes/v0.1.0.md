# v0.1.0

This document describes the first stable release source.
Publication state, download links, and checksum-bound evidence are recorded outside these source
release notes.

## Changes

- Adds the user-local `broker` process so concurrent Miller sessions with the same frozen
  broker/protocol/model identity share one loaded embedding model over local IPC.
- Keeps the spawning client as the owner through an inherited stdin lease; owner loss shuts down
  the broker without a PID file, process registry, detached daemon, or persisted ownership state.
- Serializes accelerated inference, bounds CPU inference, and exposes health facts for the
  resolved backend and accelerator state.
- Uses one user-global accelerator lease across model identities. Non-holders start on CPU, and
  proven accelerator resource exhaustion demotes the broker to CPU.
- Restricts Unix broker directories and sockets to the current user and uses current-user,
  local-only named-pipe security on Windows.
- Makes the pinned Vulkan zero stores type-explicit and rejects missing, duplicate, or nonzero
  constant-derived half-float stores during packaging.
- Preserves the frozen `julie.embedding.sidecar` v1 protocol and standalone stdio `serve`
  behavior.

## Artifact evidence boundary

RC5 passed the Rust and Python source gates, reproduced all four portable archives across two
independent hosted builds, and passed generated-SPIR-V verification in both Vulkan lanes. The
downloaded Apple arm64 RC5 archive also passed checksum-bound physical-hardware smoke and
conformance on Apple Silicon. RC5 was manually exercised on Windows and Linux.

RC5 evidence does not transfer to a stable archive because the version change produces different
executable and archive bytes. Stable support claims attach only after each exact stable archive
checksum passes its applicable real-device gate. CUDA is not included in `v0.1.0`.

## Stable release gate

Before publication, the stable artifacts must be built twice from the same source and reproduce
byte-for-byte. Each published support claim must then be bound to the exact stable archive checksum
that passed artifact validation and its applicable physical-hardware checks.

The RC5 publication record remains in
[`2026-07-28-rc5-shared-broker-release-proof.md`](../findings/2026-07-28-rc5-shared-broker-release-proof.md).
