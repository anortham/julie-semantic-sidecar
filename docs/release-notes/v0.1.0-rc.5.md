# v0.1.0-rc.5

RC5 is a local release candidate. It has not been tagged or published, so no public archive names
or SHA-256 values are claimed here. The repository README continues to identify RC4 as the current
published prerelease until RC5 publication is separately approved and verified.

## Changes

- Adds the user-local `broker` process so concurrent Miller sessions with the same frozen
  broker/protocol/model identity share one loaded embedding model over local IPC.
- Keeps the spawning client as the owner through an inherited stdin lease; owner loss shuts down
  the broker without a PID file, process registry, detached daemon, or persisted ownership state.
- Serializes accelerated inference, bounds CPU inference, and exposes health facts for the
  resolved backend and accelerator state.
- Uses one user-global accelerator lease across model identities. Non-holders start on CPU, and
  proven accelerator resource exhaustion demotes the broker to CPU instead of repeatedly failing
  or overcommitting device memory.
- Restricts Unix broker directories and sockets to the current user and uses current-user,
  local-only named-pipe security on Windows.
- Makes the pinned `diag_f16` and `tri_f16` Vulkan zero stores type-explicit before shader
  compilation and records the resulting `vulkan-repro-v4` source identity.
- Parses the generated SPIR-V during every Vulkan package build and rejects missing, duplicate, or
  nonzero constant-derived half-float stores before an archive can be produced.
- Preserves the frozen `julie.embedding.sidecar` v1 request protocol and standalone stdio
  `serve` behavior.

## Candidate package lanes

- `apple-arm64-metal-portable`
- `apple-x64-metal-portable`
- `linux-x64-vulkan-portable`
- `windows-x64-vulkan-portable`

Only archives built by the existing target-matched release tooling may be reported. A package candidate
is not a physical-hardware support claim: Apple x64 still requires exact-archive proof
on a physical Intel Mac, and Linux Vulkan and Windows Vulkan require their applicable real-device
gates. CUDA remains outside the portable RC5 candidate.

## Publication boundary

Before publication, the approval packet must record the exact source commit and clean worktree,
all feasible local gates, exact locally built archive names and SHA-256 values, and explicit
platform boundaries for targets this host cannot build. After publication, every public asset
must be downloaded, checksum-verified, manifest-verified, and broker-smoked before any consumer
pin changes.

The candidate must also pass two fresh four-platform package runs from the same commit with
byte-identical archives. Every Vulkan lane must pass the generated-SPIR-V zero-value guard in both
runs. See
[`2026-07-28-vulkan-zero-constant-reproducibility-incident.md`](../findings/2026-07-28-vulkan-zero-constant-reproducibility-incident.md)
for the failure that established this gate.
