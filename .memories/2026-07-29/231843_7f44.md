## Corrected Windows broker lifecycle test assumptions before v0.1.0

The stable release was held after the first real Windows runtime gate exposed platform-specific test defects.

- **WHAT:** Updated `tests/broker_windows_tests.rs` so its assertions match Windows named-pipe and Rust I/O semantics.
- **WHY:** The ACL test compared a materialized file-object ACE to `GENERIC_ALL`, the shutdown test expected Unix EOF instead of Windows pipe-disconnect errors, and `Write::write_all` retried `Interrupted` forever after successful cancellation.
- **HOW:** Compare the ACE with `FILE_ALL_ACCESS`; accept EOF, `ERROR_BROKEN_PIPE`, or `ERROR_PIPE_NOT_CONNECTED` as connection closure; issue one large `write` so cancellation is directly observable.
- **IMPACT:** Production broker code remains unchanged. The corrected tests can now prove the intended Windows security, connection-local shutdown, and cancellation behavior without false failures or hangs.
