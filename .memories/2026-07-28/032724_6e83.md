## WHAT

Extracted the frozen sidecar protocol's single-line processing into reusable `ProtocolReply` and `process_line` interfaces.

## WHY

The shared IPC broker needs to process one NDJSON request per connection without duplicating or changing the existing stdio protocol implementation.

## HOW

`run_loop_with_limits` retains bounded framing, newline writing, flushing, EOF, and stdio loop control. `process_line` owns the existing parse, dispatch, and compact serialization path and returns a connection-stop signal only after a reply is available.

## IMPACT

The future Unix and Windows broker transports can reuse the exact protocol behavior. Existing stdio conformance and error vocabulary remain unchanged.
